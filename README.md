# Major-Project

This project is a full-stack property listing marketplace built with Node.js, Express, and MongoDB. It supports user authentication, listing creation, image uploads via Cloudinary, and location handling using Mapbox. It uses EJS for frontend rendering, sessions for login persistence, and includes validation, flash messages, and secure session storage for smooth functionality.

Technologies & Their Uses :-
Express.js → Backend server and routing
MongoDB + Mongoose → Database and data modeling
Passport.js → User authentication
Express-session + Connect-mongo → Session management and login persistence
Cloudinary + Multer → Image upload and cloud storage
Mapbox SDK → Location and map services
EJS + ejs-mate → Server-side UI rendering
Joi → Input validation and security
Method-override → Supports PUT/DELETE in forms
CORS → Enables frontend-backend communication
Dotenv → Manages environment variables securely
Connect-flash → Displays success/error messages
